# ADR 0002: Коробки и статусы — независимые сущности

## Контекст
Две сущности для отслеживания прогресса: коробка (bucket 1..6)
и статус (new/learning/mastered). Возникает соблазн связать их.

## Решение
- Коробка — тактический интервал повторения. Меняется вручную или свайпом.
- Статус — уровень владения. Меняется вручную или автоматически
  только при первом просмотре (new → learning).
- `PATCH /cards/:id/bucket` НЕ меняет status.
- `POST /sessions/:id/swipe` НЕ переводит в mastered.
- Переход в mastered — только через `PATCH /cards/:id/status`.

## Обоснование
- Пользователь может положить карточку в «Неделю», но не считать её выученной.
- Автоматический переход в mastered ломает смысл архива.
- Разделение даёт более богатую аналитику.

## Последствия
- Пользователь явно помечает mastered — UX-нагрузка.
- В будущем SRS-рекомендации будут предлагать переход, не делать его.
