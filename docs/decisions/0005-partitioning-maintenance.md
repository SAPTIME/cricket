# ADR 0005: Обслуживание партиций

## Контекст
`events`, `page_views`, `card_session_history` партиционированы 
по месяцам. Функция `ensure_future_partitions(months_ahead)` создаёт 
партиции на N месяцев вперёд. Но её надо **вызывать регулярно**.

## Решение
- Раз в месяц запускать `SELECT ensure_future_partitions(2);` 
  через системный cron на хосте (не pg_cron — лишняя зависимость).
- Cron-задача: 1-е число каждого месяца, 03:00 UTC.
- При деплое — настроить cron в Docker-окружении.

## Обоснование
- pg_cron требует отдельного extension и усложняет Docker.
- Системный cron — просто, надёжно, видно логи.

## Последствия
- Если cron сломается — INSERT в партиционированные таблицы упадёт.
- Мониторинг: алерт, если партиция на следующий месяц не создана 
  за 3 дня до конца текущего.
